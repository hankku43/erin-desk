# 艾琳的任務櫃台（Quest NPC）

把每週工作計畫變成 RPG 任務：桌面上常駐一位 NPC，點她就能回報進度、交付任務、拿經驗值，然後接下一個委託。

## 一、安裝（只要做一次）

1. **安裝 Node.js**（LTS 版本，20 以上）：<https://nodejs.org/>
2. **安裝 Ollama**：<https://ollama.com/download>，裝完後開一個命令提示字元執行：
   ```
   ollama pull qwen3:4b
   ```
   電腦記憶體只有 8GB 的話，改用 `ollama pull qwen3:1.7b`，並把 `config.json` 裡的 `"model"` 改成 `"qwen3:1.7b"`。
3. 雙擊 **`安裝.bat`**，它會下載 Electron，大約 100MB。

> 公司網路擋 GitHub、Electron 下載失敗時，用 `安裝.bat` 裡註解掉的鏡像站設定再試一次。

## 二、啟動

雙擊 **`啟動.bat`**，艾琳會出現在螢幕右下角。

| 操作 | 效果 |
|---|---|
| 左鍵點角色 | 第一次（或隔了半小時以上）會打招呼、提醒當前任務；之後每點一下都會說一句符合她個性的閒話。12 秒內連戳三下她會開始無奈，戳五下會喵 |
| 拖曳角色 | 移動位置，會記住 |
| 右鍵角色或等級面板 | 選單：任務板、今日行程、選擇計畫檔、匯入／匯出行事曆、🤖 AI 對話與 🧠 聰明艾琳開關、設定、離開… |
| 點左下狀態面板的焦點行 | 打開任務板 |
| 滑過焦點行 | 跳出小卡：當前任務的每個目標（★ 完成／☆ 還沒）、現在這格時段的產出與進度 |
| 點焦點行左邊的圖示 | 在「現在的時段」和「當前任務」之間切換（換到下一格時段會自動切回） |
| 點等級列（Lv.、稱號那一行） | 🔮 抽今日運勢 |
| 點等級列的 🍅 | 開始專注；專注中再點一下可以提前結束 |
| 對話框的「✨ 占卜」、右鍵 →「✨ 占卜魔法」，或在聊天裡說「幫我占卜…」 | 打開占卜魔法（艾琳的星環占） |
| 按對話框或等級面板的 **▁**、右鍵 →「縮小化」 | 文字框全部收起，只剩右下角一隻小貓咪 |
| 縮小時點小貓 | 展開。縮小期間有累積提醒就說提醒，沒有的話只把縮小前的最後一句放回來，不會另外打招呼或講閒話 |
| 變身 | 縮小時貓娘會縮成一團光、貓咪彈出來；展開時貓咪發光膨脹、魔法陣亮起、星星四散，貓娘從白光中現身，等級面板和對話框隨後滑入。變身以視窗右下角為基準，所以她會留在原地換型態 |
| 右鍵 →「🖥 固定在顯示器」 | 選「自動」會跟著你拖到的那台螢幕；選某台就固定在那台，縮小、展開、重新啟動都不會跑掉。每台螢幕各自記住位置 |

### 狀態面板

左下角的面板只放一行「現在該做什麼」，細項都在任務板和滑過去的小卡裡：

- **在時段內**：⏳ 顯示這格要做的事，下面是一條小沙漏 `09:00 ━━━━── 12:00`，右邊是「剩 40 分」。剩 10 分鐘內變金色，剩 3 分鐘內變紅色閃爍。
- **不在時段內**：顯示當前任務的標題，第二行是類型和期限（今天截止、逾期幾天、還剩幾天），右邊每個目標是一顆星 ★★☆，勾完一個目標那顆星會亮起來轉一圈（在時段模式時也會先切過來讓你看一下）。
- 中午或下班後這種空檔：點圖示可以看「下一格」和還有多久開始。

### 🔮 今日運勢

每天第一次點等級列，艾琳會翻開一張運勢卡：大吉／中吉／小吉／吉／末吉（沒有凶），一句當天的建議、一個幸運物，還有一點星屑和金幣（大吉 +10 XP、+12 金幣，末吉 +3、+3）。之後再點就是再看一次，不會重複給獎勵。抽到的籤會顯示在等級列上。

### ✨ 占卜魔法（星環占）

除了每天一次的運勢，還可以隨時請艾琳占卜一件事。介面上是她奶奶教的「星環占」，背後用的是**梅花易數**：

1. 寫下想問的事，選一種起卦方式：
   - **🌀 魔法陣**：心裡默念問題，點一下讓外環（1～24）停下、再點一下讓內環（1～16）停下。
   - **🔢 報數**：自己想兩個數字打進去。
   - **🕰 此刻**：用現在的農曆年月日時起卦（會顯示像「丙午年 八月二十 巳時」）。
2. 兩個數字的報數起卦：第一個數除以 8 取上卦、第二個數除以 8 取下卦，兩數相加再加時辰數除以 6 取動爻（餘 0 算 8／算 6）。此刻起卦：年支數＋農曆月＋日除以 8 取上卦，再加時辰除以 8 取下卦，總數除以 6 取動爻。八卦用先天數：乾1 兌2 離3 震4 巽5 坎6 艮7 坤8。
3. 結果卡片會依序畫出**本卦**（現在）→**互卦**（過程）→**變卦**（結果），動爻會發金光；下面是吉凶（依體用生剋：用生體大吉、比和吉、體剋用小吉、體生用小耗、用剋體有阻），以及艾琳的解讀。AI 開著時由本機模型根據卦象用她的口吻解讀；沒開 AI 就用內建的解讀。
4. 點「📖 看解析」才會展開算式、體卦用卦、五行生剋這些細節。

**規則**：每次占卜花 **10 金幣**（艾琳說那是星粉的錢，金幣不夠她會請你先去完成委託）。**一事不二占**：同一件事 24 小時內只占一次，換個說法問也算同一件事，這時會直接給你上次的結果、不扣錢。最近的占卜會列在面板下方，點一下可以免費再看一次，花費也會記在任務板的「紀錄」。價錢和時間可以在 `config.json` 的 `divination` 改。

占卜只是參考；問到健康、法律、金錢這類重大決定，艾琳會提醒你還是要問專業的人。

> 從舊版更新過來的話，要重新執行一次 `安裝.bat`（或 `npm install`），才會裝上「此刻起卦」要用的農曆套件（lunar-javascript）。沒裝的話，另外兩種起卦方式照常能用。

### 🍅 專注模式

點等級列的 🍅（或右鍵 →「🍅 專注 25 分鐘」），艾琳說完話就變回貓咪趴在角落，頭上冒 z z，下面有倒數。專注期間她不會主動搭話，提醒會先安靜地累積成 **!**。想看還剩多久就點一下貓咪；想提前結束就再點一次 🍅（或右鍵選單）。時間到她會自己醒過來叫你休息，給 +15 星屑（XP）、+3 金幣，並記下今天第幾顆番茄。提前結束沒有獎勵。分鐘數和獎勵可以在 `config.json` 的 `focus` 改。專注到一半關掉程式也沒關係，下次開啟會接著算。

角色頭上出現 **?** 代表當前任務可以交付了，出現 **!** 代表艾琳有話要說。縮小時如果有提醒，小貓會跳一下、換成 `mini_alert` 的圖，並亮起 **!**。程式會記住上次是不是縮小狀態，下次啟動照原樣顯示。

## 用聊天更新進度

點「💬 聊聊」，直接跟艾琳說你做了什麼，她會整理成一張**確認卡**。你按「確認更新」之後才會真的改動，不想改的項目可以先取消勾選。

| 你可以這樣說 | 艾琳會提議 |
|---|---|
| 菜單定稿了 | 勾選「菜單定稿，店長回饋已處理」 |
| 新品標示全部弄完了，交付吧 | 勾選剩下的目標，然後交付任務 |
| 配方表那項勾錯了，還沒確認 | 取消勾選 |
| 我先做 P-12 | 把「P-12 + P-04」設為當前任務 |
| 今天修好 P-12，卡在測試品項，明天跑回歸 | 寫下班回報（AI 開啟時才有） |

- **AI 開著時**，由本機模型理解你的話；它只能從目前任務清單裡挑項目，挑錯或不存在的會被程式擋掉。
- **AI 沒開時**，改用關鍵字比對。說法越接近目標原文越準，例如提到「菜單」「P-12」「標示」。
- 不管哪一種都要你按確認才會生效，不會自己偷改。

## 三、遊戲規則

| 行為 | 獎勵 |
|---|---|
| 勾選一個任務目標（`- [ ]`） | +20 XP、+5 金幣 |
| 交付主線任務（必達） | +100 XP、+50 金幣 |
| 交付重要支線（主攻） | +80 XP、+40 金幣 |
| 交付支線（附帶） | +40 XP、+20 金幣 |
| 在截止日當天或之前交付 | 再加 20% |
| 勾選今日行程的一格 | +10 XP |
| 每天第一次下班回報 | +30 XP |
| 完成一次 🍅 專注 | +15 XP、+3 金幣 |
| 每天第一次抽 🔮 今日運勢 | +3～10 XP、+3～12 金幣 |
| ✨ 占卜魔法一次 | −10 金幣（一事不二占：重複問不收錢） |

- 每完成一個任務，艾琳會自動指派下一個：先派必達，再照截止日排。你也可以在任務板上自己「設為當前任務」。
- 取消勾選不會扣經驗值，但同一個目標也不會重複給獎勵。
- 決策點時間一到（例如「9/30（三）17:00 上架申請仍無回覆」），艾琳會主動提醒你計畫裡寫好的應對方式。
- 每天第一次啟動，艾琳會依時間說早安或午安，介紹今天的主題和第一件事。12:00 提醒午休、13:00 提醒回到工作、16:50 提醒準備下班交日報（時間可在 `config.json` 的 `reminders` 改）。縮小成貓咪時，提醒會先累積成 !，點開才說。

## 四、週計畫檔

一份 Markdown 就是一週的任務。最少只要這樣：

```markdown
# 本週計畫 10/5–10/9

## 新品上架 ⭐ 📅 10/6
- [ ] 營養標示完成
- [ ] 送出上架申請
```

完整一點可以加台詞、時間表、提醒（每一項都可省略）：

```markdown
## 修收銀錯價 🔧 📅 10/9
> 同一個畫面一次修完（艾琳派任務時會說這句）
- [ ] 缺價時擋下或提示
- [ ] 收銀畫面顯示警告

- [ ] 備份菜單檔 🌿            ← 不在任務底下的一行，自己就是一個任務

## 週二 10/6｜新品上架
- 09:00–10:30 營養標示 → 標示 PDF
- 13:30 寄出上架申請
- ⏰ 17:00 申請沒回覆 → 打電話追一次
```

| 寫法 | 意思 |
|---|---|
| `# 標題` | 計畫名稱，**每週要不一樣**（程式用它區分是哪一週） |
| `## 任務名 ⭐ 📅 10/6` | 一個任務。⭐ 必達／🔧 主攻／🌿 順手（沒寫就是主攻）；日期是截止日，`📅` 可省略 |
| `> 一句話` | 緊接在任務標題下，艾琳派任務時會說 |
| `- [ ] 目標` | 任務底下的勾選就是目標；目標寫完空一行，後面的勾選就算獨立任務 |
| `## 週二 10/6｜主題` | 一天的時間表。有星期字或「日期｜」就算一天；`## 10/6` 也可以 |
| `- 09:00–10:30 做某事 → 產出` | 時間表的一格；只寫開始時間也可以 |
| `- ⏰ 17:00 條件 → 應對` | 提醒，時間到艾琳會說。放在某一天底下就用那天的日期，也可以寫 `⏰ 10/9 12:00 …` |
| `## 進度紀錄` | 下班回報會自動寫在這裡，不用自己建 |

**跟筆記軟體相容**：Obsidian Tasks 的記號都看得懂，`📅 2026-10-06` 是截止日、`⏫`/`🔼`/`🔽` 是優先度（對應 ⭐/🔧/🌿）、`✅ 2026-10-05` 是完成日。艾琳勾選時也會照這個慣例寫回 `- [x] … ✅ 日期`，在 Obsidian 裡打開完全正常。`## Tasks` 這種純文字標題會當成分組，底下每一行各算一個任務；縮排的子項是它的目標。

**換週**：複製 `plans/_template.md` 改內容，或右鍵 →「選擇週計畫檔…」。`plans/` 裡除了 `_template.md` 和 `week_sample.md`，其他檔案都不會進 git。

**在程式裡新增／修改**：不想開編輯器也可以，改動都會直接寫進同一份 Markdown，之後在檔案裡看得到、也能繼續手改。

| 在哪裡 | 按鈕 | 做什麼 |
|---|---|---|
| 任務板標題列 | **＋ 新任務** | 填名稱、類型（主線 ⭐／重要支線 🔧／支線 🌿）、截止日、一句話說明、目標（一行一個），寫成一個 `## 任務` 區塊放在最後一個任務後面 |
| 任務卡展開後 | **＋ 目標** | 在任務底下加一行 `- [ ]`，按 Enter 可以連續加 |
| 任務卡展開後 | **✎** | 改名稱、類型、截止日、說明（目標請用 ＋ 目標 和 ✕ 調整）。改名後已勾選的進度會跟著搬過去 |
| 任務卡展開後 | **🗑** | 刪掉整個任務（會先問一次），連目標一起 |
| 目標右邊（滑過去出現） | **✕** | 刪掉那一個目標 |
| 今日行程標題列 | **＋ 時段** | 日期、開始／結束時間、要做什麼、產出，寫成 `- 09:00–10:30 …` 放進那一天（那一天不存在會自動建） |
| 今日行程標題列 | **⏰ 提醒** | 日期、時間、提醒什麼、到時怎麼做，寫成 `- ⏰ 17:00 條件 → 應對`；決策點就是這樣設的 |
| 時段／提醒右邊 | **✕** | 刪掉那一行（會先問一次） |

已交付的任務不能改；舊格式（表格版）的計畫檔沒有這些按鈕，先轉成新格式。

**回寫**：勾選目標時會把 `- [ ]` 改成 `- [x] … ✅ 日期`，勾選今日行程的一格會把那一行改成 `- [x] 09:00–10:30 …`，下班回報會寫進檔案最後的「進度紀錄」。第一次修改前原檔會自動備份到 `data/backups/`。不想讓程式改原檔，把 `config.json` 的 `plan.writeBack` 設成 `false`（新增／刪除也只會留在記憶體裡）。在外部編輯器修改後，程式約 3 秒內會自動重新載入。

**舊格式（表格版週報）**：`node tools/convert_plan.js 舊檔.md 新檔.md` 可以轉成新格式。

### 跟 Google／Outlook 行事曆互通（.ics）

不用連帳號、不用 API，靠行事曆都支援的 `.ics` 檔來回搬。

**匯入**（行事曆 → 週計畫）：今日行程的「📥 匯入」或右鍵 →「📥 匯入行事曆（.ics）到本週…」，選一個 `.ics` 檔就好。

- 從哪裡拿 .ics：Google 日曆 → 設定 → 匯入及匯出 → 匯出（會是一個 zip，解開就有每個日曆的 .ics）；Outlook → 檔案 → 開啟和匯出 → 匯入／匯出 → 匯出至檔案（iCalendar）；Apple 行事曆 → 檔案 → 匯出。
- 只會拿**計畫那一週**（週一到週日）的事件，其他的不動。
- 有開始時間的事件 → 寫成那一天的一格 `- 14:00–16:00 專案週會（3F 會議室）`，照時間順序插進去；全天事件（假日、出差）→ 接在那一天標題的主題後面，例如 `## 週四 10/1｜試吃會日、出差台中`。
- 每週重複、每月第幾個星期幾、隔週、到某天為止、次數、單次改時間或取消的例外，都會照行事曆的規則展開；已取消的事件不匯入。
- 同一個事件再匯一次不會重複（記得 UID；就算換了電腦，同一天同時間同標題也會擋掉）。

**匯出**（週計畫 → 行事曆）：今日行程的「📤 匯出」或右鍵 →「📤 匯出本週成行事曆（.ics）…」，存成 `.ics` 後到 Google 日曆（設定 → 匯入）或 Outlook（匯入 iCalendar）選這個檔。

- 時間表的每一格 → 一個事件（只寫開始時間的算 30 分鐘；產出放在說明裡，做完的會加 ✅）。
- 提醒 `⏰` → 15 分鐘的事件，附行事曆鬧鐘。
- 有截止日的任務 → 那天的全天事件「⭐ 截止：任務名」，目標清單放在說明裡（沒寫截止日、預設「本週內」的不會匯出）。
- 事件的 UID 是固定的，重複匯入時行事曆能靠它認出同一個事件（Google 會略過已存在的；Outlook 匯入時選「不要匯入重複項目」）。

## 五、換成你自己的角色

把圖片放進 `assets/character/`，檔名如下（沒提供的表情會用相近的圖代替：`shy` → `happy`、`disdain` → `thinking`，其他 → `normal`）：

| 檔名 | 用在 |
|---|---|
| `normal.png` | 平常（**必要**） |
| `happy.png` | 稱讚、完成目標 |
| `cheer.png` | 交付任務、升級 |
| `thinking.png` | 思考、提醒行程 |
| `surprised.png` | 驚訝 |
| `worried.png` | 逾期、卡關 |
| `shy.png` | 害羞：被稱讚、被說中心事 |
| `disdain.png` | 鄙視：ゴミを見るような目（開玩笑時用） |
| `mini.png` | 縮小化時的貓咪型態（沒有的話會用 normal 縮小） |
| `mini_alert.png` | 縮小時有新提醒 |

**AI 生成提示詞**（白髮藍眼貓娘＋貓咪縮圖）請看 `assets/character/PROMPTS.md`。

頭上的提示圖示（藍色貓耳問號＝可以交付、粉色貓耳驚嘆號＝有新訊息）放在 `assets/ui/`。想換成自己的圖，就把 `marker_ready.png`、`marker_alert.png` 放進 `assets/character/`，建議做成 128×128 的透明 PNG。

- 格式：PNG 或 WebP，**要透明背景**。建議高度 800–1200px，程式會自動縮放。
- 動態 WebP 或 APNG 也可以直接用，角色就會動。
- 所有表情要同尺寸、同位置，切換時才不會跳動。
- 放好圖片後，右鍵 → 離開，再重新啟動。
- 目前的 SVG 是原創佔位角色，由 `tools/make_placeholder_character.py` 產生，刪掉即可。

## 六、艾琳的角色設定（lore/艾琳.md）

艾琳有一份完整的背景故事：北方霜月村來的白毛貓族、星盾公會三號櫃台的接待員、老闆是一隻叫霍伯的貓頭鷹……跟她聊工作以外的話題（你幾歲、老家在哪、Python 是什麼、我好累），她會用這份設定回答。

運作方式：檔案最上面那段「角色核心」每次對話都會給 AI；下面每個 `##` 是一條設定，程式會依你說的話挑出最相關的 2～3 條給 AI 參考（BM25 關鍵字比對，零延遲）。AI 沒開的時候，關鍵字直接命中的設定會用預寫好的「台詞」回答。

想改她的故事，右鍵 →「開啟角色設定檔」，照現有格式加一段就好：

```
## 標題
關鍵字：問到這些詞會命中、用頓號隔開
表情：happy
台詞：AI 離線時直接說的一句話
設定內文，給 AI 參考用。
```

改完右鍵 →「重新讀取設定」。

**🧠 聰明艾琳（選用）**：執行 `ollama pull qwen3-embedding:0.6b` 之後，右鍵 →「🧠 聰明艾琳（向量搜尋）」打勾，艾琳查角色設定時除了關鍵字還會用語意比對，換個說法問也找得到（例如「你是哪裡人」也能命中「故鄉」）。代價是每句聊天多 0.5～1 秒，記憶體多用約 1GB；覺得慢或想省記憶體就取消勾選，馬上改回只用關鍵字。選單下一行會顯示狀態（就緒／計算中／連不到 Ollama／還沒裝向量模型）。這個開關跟「🤖 AI 對話」分開，只要 Ollama 有開就能用；Ollama 晚一點才開、或剛裝好向量模型，程式會自己再試。設定向量只算一次，存在 `data/lore_vectors.json`，改了角色設定只會重算改到的那幾條。

## 七、設定（config.json）

| 設定 | 說明 |
|---|---|
| `npc.name`、`role`、`personality`、`catchphrases` | NPC 的名字、身分、個性、口頭禪，AI 會照這些演 |
| `npc.callName`、`npc.selfName` | 她怎麼叫你（預設「冒險者」）、怎麼稱呼自己（預設用 `name`，也就是「艾琳」，不說「我」）。AI 偶爾不聽話時，程式會把回覆裡的「我」「玩家」「主人」「您」自動改回來；任務名稱和你自己寫的字不會被改 |
| `divination.cost`、`divination.repeatHours` | ✨ 占卜一次花多少金幣（預設 10）、同一件事幾小時內不能再占（預設 24） |
| `focus.minutes`、`focus.rest`、`focus.xp`、`focus.gold` | 🍅 專注的分鐘數（預設 25）、提醒休息幾分鐘（5）、完成的星屑與金幣（15、3） |
| `llm.enabled` | `false` 就不用 AI，只用內建台詞 |
| `llm.model` | Ollama 模型名稱 |
| `llm.timeoutMs` | 閒話、提醒這類 AI 回應的逾時（預設 45 秒），逾時就改用內建台詞 |
| `llm.chatTimeoutMs` | 聊天的逾時（預設 90 秒）。聊天要帶任務清單和角色設定，提示最長；沒有 GPU 的電腦常常要 30 秒以上 |
| `llm.numCtx` | 給模型的 context 長度（預設 4096）。每次呼叫都用同一個值，Ollama 才不會一直重新載入模型 |
| `rewards` | 所有經驗值和金幣數字 |
| `window.idleChatterMinutes` | 在排定的時段內，每隔幾分鐘主動提醒一次行程（0 = 關閉） |
| `window.transformFx` | `false` 關閉變身特效 |
| `window.transformInPlace` | `false` 的話，縮小／展開改回各自記住的位置，不原地變身 |
| `reminders.items` | 作息提醒。預設 12:00 午休、13:00 上班、16:50 準備下班；`event` 可填 `lunch`／`afternoon`／`wrapup`，或不填、改用 `label` 寫自己的提醒文字 |
| `reminders.weekdaysOnly` | `true` 時週末不提醒 |
| `reminders.graceMinutes` | 開機時如果提醒時間已經過了，在這幾分鐘內還是會補說一次 |
| `lore.path` | 角色設定檔位置 |
| `lore.topK` | 每次對話最多給 AI 幾條設定 |
| `lore.embeddings` | 🧠 聰明艾琳開關（右鍵選單會改這個）。`true`／`"auto"`：有向量模型就用；`false`：只用關鍵字 |
| `lore.embedModel` | 向量模型名稱，預設 `qwen3-embedding:0.6b` |

修改後，右鍵 →「重新讀取設定」。

對話框名字旁邊的小圓點就是 AI 的狀態，**點一下可以直接開關 AI**：

| 圓點 | 意思 |
|---|---|
| 🟢 綠色 | AI 已連線，艾琳的話由本機模型即時生成 |
| 🟠 琥珀色閃爍 | AI 開著但連不上 Ollama（沒啟動、模型沒下載），先用內建台詞；程式每 20 秒會自動重試，連上後會提示 |
| ⚪ 灰色 | 你手動關掉了 AI，只用內建台詞 |

右鍵選單裡也有「🤖 AI 對話」開關、目前狀態，和「立刻重新連線」。開關會寫回 `config.json`，下次啟動記得。

**自動重連怎麼運作**：離線時每 20 秒探一次 Ollama，連線中每 2 分鐘確認一次。回太慢（逾時）不算斷線：狀態還是綠燈，接下來 2 分鐘內戳她、提醒這類順便說的話先用內建台詞，免得一直卡；你在聊天裡問的話照樣會問 AI。連上時會先在背景把模型載進記憶體（暖機），第一句就不用等太久。斷線期間你的操作不會被卡住，全部走內建台詞。

## 八、資料在哪裡

- `data/save.json`：等級、經驗值、金幣、交付紀錄、艾琳的記憶。換電腦時一起帶走就好。
- `data/backups/`：計畫檔修改前的備份。
- `data/llm.log`：每次呼叫 AI 的耗時紀錄（除錯用，可以隨時刪）。
- 所有資料都在這台電腦上，AI 也在本機執行，**任務內容不會傳到網路上**。

## 常見問題

- **艾琳一直用固定台詞**：確認 Ollama 有在執行（工作列有羊駝圖示），而且 `ollama list` 看得到設定的模型。聊天時句首的括號會說明原因：「連不到 AI」「AI 想太久了」「AI 對話已關閉」。這些備援句子不會存進給 AI 看的對話紀錄，AI 不會學著照說。
- **想知道 AI 為什麼慢**：打開 `data/llm.log`，每次呼叫一行，寫著花了多久、載入模型多久、讀了多少提示、產生多少字，失敗的也會記原因（最多留 300 行）。「載入模型」常常很久的話，代表模型一直被換出記憶體。
- **回話很慢**：第一次呼叫要載入模型，會慢 10–30 秒，之後就會變快。還是太慢的話改用 `qwen3:1.7b`。
- **偶爾出現簡體字**：`npm install` 時會一起裝繁簡轉換套件 opencc-js，確認安裝時沒有報錯。
- **點不到桌面上角色後面的東西**：只有卡片和角色本身會攔截滑鼠，空白處可以直接穿透點到後面的視窗。

## 從 GitHub 拿回來繼續開發

```
git clone https://github.com/<你的帳號>/erin-desk.git
cd erin-desk
npm install
ollama pull qwen3:4b        # 第一次；沒裝 Ollama 也能跑，只是用內建台詞
npm start
```

第一次啟動會自動從 `config.example.json` 建立 `config.json`；存檔、備份、向量快取都在 `data/`，這兩個都不進 git，所以在家和公司的進度是分開的（想同步就把 `data/save.json` 帶過去）。

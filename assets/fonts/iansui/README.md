# 芫荽 Iansui

艾琳的筆記本（📓 委託）用的手寫風字型。

- 字型：芫荽 Iansui，作者 The Iansui Project Authors（https://github.com/ButTaiwan/iansui）
- 授權：SIL Open Font License 1.1（全文在 `OFL.txt`），可以免費使用、隨程式一起散布；不能單獨拿字型去賣
- 檔案：取自 npm 套件 `@fontsource/iansui` 5.3.1，只留 woff2（依字元範圍切成很多小檔，用到才載入）
- 不想用：筆記本右上「⋯」→「✍ 手寫字型」關掉，或 `config.json` 的 `planDraft.handFont` 設成 `false`
